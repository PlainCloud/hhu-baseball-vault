# Base Running Relay Race
**跑垒接力赛**

> [!info] 项目信息
> - **运动项目**：棒球 / 垒球
> - **类别**：Baserunning 跑垒
> - **难度**：初级
> - **时长**：约 10 分钟
> - **人数**：3-18 人
> - **适用年龄**：4-6、7-8、9-10
> - **所需器材**：垒包、标志锥
> - **场地要求**：整个球场

## 项目简介

竞技性接力赛，证明正确技术胜过纯粹的速度。各小组比赛绕垒跑，以最佳合计用时取胜。

## 训练步骤

1. 把球员分成 2-4 人一组。每组在本垒板前排好队。
2. 听到开始信号后，每组第一名球员尽快完整绕垒跑一圈。
3. 该球员一触到本垒板，同组下一名球员立即出发。
4. 持续进行，直到每组所有球员都绕垒跑完。合计用时最快的小组获胜。
5. 用标志锥标出每个垒包正确的转弯路线——抄近道切角的球员取消资格。
6. 你会发现，绕垒跑得正确的小组往往能战胜跑得更快但动作更粗糙的小组。

## 教练要点

- 正确的基本功胜过纯粹的速度——本练习能证明这一点
- 用标志锥标出正确的转弯路线
- 踩每个垒包的内侧，并蹬向下一垒
- 为每组计时并比较——很适合说明技术很重要
- 取消抄近道切角球员的资格
